# 資料視覺化強化設計

## 概述

全面強化 ReportView 報表頁面，新增年度趨勢、跨月比較、消費熱力圖三大功能區塊。採用 tab 切換架構整合於現有 ReportView，圖表技術統一使用 Chart.js。

## 技術選型

- **圖表庫**：Chart.js + vue-chartjs（延續現有技術棧）
- **新增依賴**：`chartjs-chart-matrix`（熱力圖矩陣插件）
- **互動層級**：中等（hover tooltip + 點擊 drill down 到交易明細）

## 架構：ReportView Tab 切換

| Tab | 名稱 | 內容 | 狀態 |
|-----|------|------|------|
| 月報表 | 現有功能 | 當月圓餅圖 + 每日長條圖 | 預設 tab |
| 年度趨勢 | 新增 | 折線圖 / 三線圖 / 堆疊面積圖 | 新增 |
| 跨月比較 | 新增 | 雙月並排 / 多月疊圖 / 同期比較 | 新增 |
| 消費熱力圖 | 新增 | 星期x時段 / 日曆格 / 分類x月份 | 新增 |

頂部橫向 tab bar，月報表為預設。每個 tab 內的子視圖用 toggle 按鈕切換。

## Tab 1：月報表（現有功能）

維持不變：當月圓餅圖（分類佔比）+ 每日長條圖（支出趨勢）+ 月份導航。

## Tab 2：年度趨勢

### 時間範圍
- 年份選擇器（預設當年），左右箭頭切換
- 顯示 1-12 月資料，不足月份留空

### 模式 A：每月總支出折線圖
- 單一折線，X 軸月份、Y 軸金額
- Hover 顯示該月總支出金額
- 點擊某月 → 跳轉到月報表 tab 並切換到該月

### 模式 B：支出 + 收入 + 結餘
- 三條折線同一張圖，不同顏色（紅/綠/藍）
- 圖例可點擊顯示/隱藏個別線條
- Hover tooltip 同時顯示三個數值

### 模式 C：分類堆疊面積圖
- X 軸月份，Y 軸金額，每個分類一個色塊堆疊
- 只顯示支出 top 5 分類，其餘合併為「其他」
- Hover 顯示該月各分類金額
- 點擊某分類色塊 → 顯示該分類全年明細

### 元件
- `YearlyTrendChart.vue`

---

## Tab 3：跨月比較

### 模式 A：雙月並排比較
- 兩個月份選擇器，各選一個月
- 並排顯示兩張圓餅圖（分類佔比）
- 下方表格列出各分類金額差異（金額 + 增減百分比），紅升綠降
- 點擊分類 → 展開該分類在兩個月的交易明細

### 模式 B：多月疊圖
- 可勾選最多 4 個月份
- 同一張長條圖，X 軸為分類，每個分類有 N 根並排柱子代表不同月份
- Hover tooltip 顯示各月份金額
- 點擊某柱子 → 顯示該月該分類的交易列表

### 模式 C：同期比較
- 自動顯示「本月 vs 上月」和「本月 vs 去年同月」
- 兩組卡片式摘要：總支出增減 %、各分類前三大變動
- 無需手動選月，打開就有資訊
- 點擊卡片 → 切換到模式 A 並帶入對應兩個月

### 元件
- `MonthCompareChart.vue`

---

## Tab 4：消費熱力圖

### 模式 A：星期 x 時段
- 7 行（週一到週日）x 24 列（0-23 時）的格子矩陣
- 顏色深淺代表該時段消費總金額
- 上方可選時間範圍（近 1 月 / 3 月 / 6 月 / 1 年）
- Hover 顯示「週三 14:00-15:00：共 $2,340（8 筆）」
- 點擊格子 → 顯示該時段的交易列表
- 需要交易有時間欄位（見下方「交易時間欄位」）

### 模式 B：日曆格（GitHub contribution 風格）
- 橫向 52 週 x 7 天
- 預設顯示近一年，可切換年份
- 顏色深淺代表當日消費金額（分 5 級：無消費、低、中、高、極高）
- Hover 顯示「2026-03-13：$850（3 筆）」
- 點擊某天 → 顯示當日交易列表

### 模式 C：分類 x 月份
- Y 軸為分類（支出 top 8），X 軸為 12 個月
- 每個格子顏色深淺代表該分類該月消費金額
- 預設顯示當年，可切換年份
- Hover 顯示「飲食 / 3 月：$12,500」
- 點擊格子 → 顯示該分類該月的交易列表

### 元件
- `HeatmapChart.vue` — 使用 `chartjs-chart-matrix` 插件

## 交易時間欄位（新增）

為支援「星期 x 時段」熱力圖，交易記錄需新增時間資訊。

### 變更內容
- `AddView.vue`：`<input type="date">` 改為 `<input type="datetime-local">`
- 預設值：新增交易時帶入當前日期 + 時間
- 儲存格式：ISO datetime（如 `2026-03-14T14:30`）

### 向下相容
- 現有交易只有日期（`YYYY-MM-DD`），視為當日 `00:00`
- DB 不需升版：`date` 索引不受影響，值格式改變但排序仍正確
- CWMoney 匯入：若來源有時間就帶入，沒有就保持 `00:00`

## Drill Down 交易明細

所有圖表的點擊 drill down 統一使用**底部滑出面板（bottom sheet）**。

### 行為
- 點擊圖表元素 → 底部滑出半高面板
- 手機：向上滑出、向下滑動關閉
- 桌面：半高面板，點擊外部或按 X 關閉

### 面板內容
- 標題：顯示篩選條件（如「2026 年 3 月 / 飲食」）
- 交易列表：日期、分類、金額、備註
- 點擊單筆交易 → 跳轉到 AddView 編輯頁

### 元件
- `DrillDownPanel.vue` — 可重用的底部滑出面板
